Will this mix pass M30? Know it 28 days early.

Concrete is accepted only after its test cubes are crushed at 28 days. StrengthLab predicts the crushing strength of a mix from its recipe, and the chance it meets an IS 456 grade, using linear models, Bayesian inference, kernels and support vector machines all written from scratch.

Kernel functions · the kernel trick

Bend the line without the features.

Kernel ridge regression only ever sees similarities k(x, x') = exp(−γ‖x − x'‖²). Tune γ and λ: the model is refitted live on 704 mixes by solving a = (K + λI)⁻¹t. Watch the strength-gain curve for a reference mix, and watch overfitting happen.
